Not connected · API unavailable

No verified node endpoint is published

The blockchain repository includes persistent node-state storage and an internal authenticated TCP request protocol in its current development work. That protocol is for node-to-node communication; it is not a public, browser-safe HTTP explorer API. No verified public endpoint is configured.

Before live explorer queries are possible, the project still needs a documented read-only HTTP API or secure gateway, schema and pagination guarantees, API integration tests against validated chain state, and a configured monitored testnet endpoint. Until then, this page cannot safely look up block heights, block hashes, transactions, addresses, or balances.

AddressesUnavailable — wallet and balance API not implemented

What must exist before live explorer data

  1. A validated, persistent chain database with deterministic block and transaction identifiers.
  2. A read-only node API with documented schemas, pagination, and input limits.
  3. Integration tests proving API responses match independently validated chain state.
  4. A configured, monitored public testnet endpoint. The browser must never connect to an arbitrary untrusted node by default.
