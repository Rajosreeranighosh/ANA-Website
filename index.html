Technology

Open development. Verifiable foundations.

ANA's current engineering work focuses on a Rust-based node, RandomX proof of work, and authenticated peer communication.

⌘

RandomX PoW

A CPU-oriented proof-of-work design using the RandomX algorithm. Mining and consensus behavior remain under active development.

⛓

Rust node

The node implementation is written in Rust, with an emphasis on explicit validation, testing, and maintainable systems code.

⇄

Authenticated peers

TLS 1.3 mutual-authenticated peer transport is being developed in draft PR #41. It is not yet merged or approved for public deployment.

Tokenomics

A proposed fixed supply.

The project target is a maximum supply of 21 million ANA. Issuance rules, reward schedule, and consensus enforcement must be fully implemented and independently tested before any launch claims.
